End-to-End Request Lifecycle: Frontend ➔ Backend ➔ Cloud

Step 1: Frontend User Request Initiation
The user submits a free-text outage complaint on the React 19 UI (Dashboard.tsx). The custom hook useOrchestration.ts opens an SSE connection stream to POST /orchestrate/stream on IBM Cloud Code Engine.
Step 2: FastAPI Security Ingress & PII Masking
Before touching any agent logic, PIIGuardrails.mask_input() redacts sensitive customer data (phones, emails, credit cards), InputGuardrails.validate() checks for SQL/prompt injections, and verify_orchestrate_key() validates the x-api-key header.
Step 3: 7-Agent Execution & Vector DB RAG Search
The Master Orchestrator coordinates the specialized agents:
1. Intent Recognition   ➔ IBM NLU extracts entity="Manhattan", service="4G", priority="Critical"
2. Ticket Classification➔ Generates INC-2026-042871, queue="Network_Ops", SLA=30 mins
3. RCA Agent (Vector DB)➔ Queries ChromaDB vector store for top-5 historical incidents + watsonx.ai Granite 13B reasoning
4. Parallel Execution   ➔ Concurrent asyncio.gather: Escalation Agent (Executive alert) + Parallel Impact Agent (50k users)
5. Resolution Agent     ➔ Formulates step-by-step resolution plan & customer message
6. Feedback Agent       ➔ Calculates CSAT score (0.92) & preventive action points
Step 4: IBM BOB Ticket Automation & Cloudant Audit Write
IBM BOB workflow triggers on skill completion and automatically writes the full incident record into the Cloudant tickets database. Anonymized execution traces are committed to audit_trail.
Step 5: SSE Streaming & React 19 UI Animation
FastAPI streams SSE chunk events back to the React UI. Pipeline node icons light up green in real time, confidence meters update, and final resolution steps render with copy-to-clipboard functionality.
